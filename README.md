# 🎓 Engineering Formula Calculator & AI Assistant
🚀 **Live Demo:** [engineering-formula-calculator.streamlit.app](https://engineering-formula-calculator.streamlit.app)
A modern, interactive Streamlit web application designed for B.Tech engineering students to execute core mathematical and physical computations with step-by-step validation. Built using Python, Streamlit, and a custom Rule-Based Natural Language Processing (NLP) engine for dynamic formula recommendation.

---

## 🌟 Key Features

* 📐 **Engineering Mathematics Module:** Interactive calculators for 2x2 Matrix Addition, Matrix Multiplication, Determinants, Matrix Inverses, 3D Vector Magnitudes, and Vector Dot Products.
* ⚡ **Engineering Physics Module:** Computational tools for Classical Mechanics (Force, Velocity, Acceleration, Momentum, Work, Power, Kinetic Energy), Fluid Statics (Pressure, Density), and Circuit Theory (Ohm's Law).
* 🤖 **Rule-Based AI Assistant:** Natural language query parser that extracts keywords from plain-English student questions to recommend exact formulas and scientific logic.
* 🛡️ **Defensive Exception Guarding:** Built-in validation guarding against division-by-zero (t=0, A=0, det(A)=0) and non-numeric inputs.
* 📊 **Interactive Dashboard UI:** Sidebar navigation, key performance indicator (KPI) metric cards, and responsive tabbed views.

---

## 🛠️ Tech Stack & Concepts Implemented

* **Language:** Python 3.x
* **UI Engine:** Streamlit
* **Architecture:** Modular Package Architecture (math_engine.py, physics_engine.py, ai_engine.py)
* **AI Parser:** Rule-Based NLP Pipeline with Keyword Scoring & Regular Expressions (re)
* **Academic Curriculum:** JNTUK R23 B.Tech Engineering Mathematics & Physics
